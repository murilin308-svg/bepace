# MP97

MASTER PROMPT — LIFE OPERATING SYSTEM

Crie uma aplicação web premium chamada provisoriamente de Life Operating System, funcionando como um verdadeiro Sistema Operacional da Vida.

Não quero apenas uma ferramenta de produtividade.

Quero construir um ecossistema pessoal completo, no qual o usuário consiga visualizar, organizar, planejar e acompanhar sua vida em um único ambiente.

A plataforma deve transmitir a sensação de:

“Este é o meu centro de comando pessoal.”

O sistema deve unir:

Clareza

Controle

Foco

Organização

Sofisticação

Crescimento

Bem-estar

Experiências

Evolução contínua

O produto precisa parecer extremamente bem pensado, premium, minimalista e fluido.



01. DIREÇÃO VISUAL — MUITO IMPORTANTE

Utilize as 3 imagens anexadas a este prompt como referências visuais prioritárias.

Quero que a interface final fique muito próxima da linguagem visual apresentada nessas referências, adaptando-a para a identidade própria do Life Operating System.

Não copie logos, marcas, textos ou identidade das referências.

Copie apenas a linguagem de design, composição, proporções, profundidade, organização, espaçamento e sensação visual.

REFERÊNCIA 01 — DASHBOARD

A interface deve utilizar grandes superfícies escuras, divisórias discretas e cards organizados.

A sidebar deve parecer integrada ao produto, não simplesmente adicionada sobre ele.

O dashboard deve transmitir imediatamente organização e controle.

REFERÊNCIA 02 — LAYERS OF BLACK

Essa referência é fundamental para a identidade visual.

Utilizar o conceito:

Layers of Black.

Não utilizar simplesmente um fundo preto com cards pretos.

Criar diferentes níveis de profundidade através de tons muito próximos:

Preto profundo

Preto fosco

Grafite

Cinza carvão

Bordas discretamente mais claras

Os elementos devem parecer estar em camadas.

Alguns cards podem parecer levemente elevados ou suspensos.

Utilizar:

sombras extremamente suaves;

contraste tonal;

bordas sutis;

profundidade controlada;

iluminação quase imperceptível.

O resultado deve transmitir luxo discreto.

REFERÊNCIA 03 — LOGIN

A terceira imagem é a principal referência para a tela de autenticação.

Preservar sua lógica de composição.

Criar um grande container principal preto, horizontal, com cantos bastante arredondados.

Dentro dele:

Lado esquerdo: área conceitual e de identidade da plataforma.

Lado direito: painel de autenticação.

O formulário NÃO deve simplesmente estar colocado sobre o fundo.

Ele deve ficar dentro de um painel preto fosco próprio, ligeiramente diferente do preto ao redor.

Esse painel deve possuir:

cantos arredondados;

espaçamento interno generoso;

contraste tonal muito sutil;

sensação de profundidade;

aparência de card;

sensação de estar encaixado ou levemente suspenso.

O logo presente na referência é apenas inspiração de posicionamento.

Não reproduzir o logo Golden Suisse.

O logo definitivo do Life OS será inserido posteriormente.

23. CONEXÃO ENTRE OS MÓDULOS

Extremamente importante.

Não desenvolver cada módulo como um aplicativo isolado.

O valor do Life OS está na conexão entre eles.

Exemplos:

Uma meta pode gerar tarefas no calendário.

Um hábito influencia o Life Score.

Uma viagem aparece no Calendar e no Travel.

Uma reflexão do Journal pode ser vinculada a uma meta.

Uma nota pode virar conteúdo do Knowledge.

Objetivos concluídos alimentam estatísticas do Profile.

O Dashboard agrega informações de todos os módulos.

O sistema inteiro deve funcionar como uma única inteligência organizada sobre a vida do usuário.



24. REGRA DE EXPERIÊNCIA

Cada tela deve responder a três perguntas:

Onde estou?

O que importa aqui?

Qual é minha próxima ação?

Não sobrecarregar o usuário.

Utilizar progressive disclosure.

Mostrar primeiro o essencial.

Detalhes aparecem quando necessários.



25. RESULTADO FINAL ESPERADO

O resultado não deve parecer:

“mais um aplicativo de produtividade”.

Deve parecer:

Um sistema operacional pessoal.

Um lugar onde o usuário consegue visualizar:

onde está,
onde quer chegar,
o que está fazendo,
o que viveu,
o que aprendeu
e como está evoluindo.

A experiência deve transmitir:

controle sem complexidade.

profundidade sem poluição.

tecnologia sem frieza.

luxo sem ostentação.

Visualmente, manter como princípio central:

Layers of Black + White + Orange Accent.

As três referências anexadas são a principal fonte de direção visual.

Em caso de conflito entre uma tendência genérica de dashboard e essas referências, priorizar as referências anexadas.

O resultado final deve parecer um produto digital premium, maduro e cuidadosamente projetado — não um template SaaS.
